# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any of my repositories, please **do not** open a public GitHub issue.

Instead, use one of these:

- **GitHub Private Vulnerability Reporting** (preferred): use the "Report a vulnerability" button on the Security tab of the affected repository.
- **Email**: [frances@francescoronel.com](mailto:frances@francescoronel.com)

Your report should include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

I will acknowledge your report within 72 hours and work with you to resolve the issue promptly.

## Scope

This policy applies to all public repositories under [github.com/FrancesCoronel](https://github.com/FrancesCoronel).

## Preferred Languages

I prefer all communications to be in English.

## Thank you

Thank you for helping keep my projects secure. I appreciate responsible disclosure.
